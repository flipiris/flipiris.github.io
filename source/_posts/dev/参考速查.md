要写文章、隐藏某个菜单分类或给作品加素材，从对应示例开始。实现细节见[代码逻辑](/code-logic/)，可视预览见[外观实验室](/appearance-lab/)，仓库入口见 [README](https://github.com/flipiris/flipiris.github.io#readme)。

# 写作与本地预览

```bash
npm ci
npm run server
```

打开 <http://localhost:4000/>。内容和样式修改后自动刷新；修改 `_config.yml` 或 `themes/iris-paper/_config.yml` 后重启预览。移动文件、删除页面或调整生成器后，执行 `npm run clean && npm run build`。

## 新建文章

```bash
npm run new -- --slug night-notes "夜记"
mkdir -p source/_posts/notes
mv source/_posts/night-notes.md source/_posts/notes/
```

```yaml
---
title: 夜记
date: 2026-11-12 10:00:00
permalink: night-notes/
layout: article
tags: [随笔]
---
```

元数据后空一行写正文。`permalink` 固定链接，移动分类目录时仍可保持 `/night-notes/`。目录决定分类，front matter 的 `categories` / `category` 不生效。

## 独立页、画布和草稿

```bash
npm run page -- about
npm run canvas -- --slug night-journey "夜行"
npm run draft -- --slug unfinished "未完成"
npm run server -- --draft
npx hexo publish unfinished
```

独立页位于 `source/about/index.md`，默认使用 `page`。画布先生成在 `_posts/`，可移到 `works/`。草稿保存在 `_drafts/`；发布后补 permalink，再移进对应分类目录。

# 配置菜单与分类

主题配置位于 `themes/iris-paper/_config.yml`。

## 固定入口并排显示

`nav_primary` 按配置顺序排成两列，不显示图标。可在现有列表中追加页面：

```yaml
nav_primary:
  - label: 最近更新
    path: /updates/
  - label: 页面一览
    path: /archives/
  - label: 分类索引
    path: /categories/
  - label: 标签索引
    path: /tags/
```

这些页面的内容各不相同：最近更新按 `updated || date` 排序，包含独立页；页面一览是按发布日期排列的文章归档；分类、标签索引按卡片分页。`taxonomy_per_page` 控制每页卡片数，`taxonomy_preview` 控制每卡预览篇数。

## 分类存在，但不在菜单里建立入口

在分类项增加布尔值 `nav: false`：

```yaml
sections:
  - folder: notes
    label: 笔记
    icon: edit_note
  - folder: dev
    label: 开发
    icon: code
    nav: false
```

每项字段：

- `folder`：目录名，同时用于分类网址。
- `label`：分类显示名。
- `icon`：Material Symbols Rounded 图标名。
- `nav`：省略或 `true` 时显示菜单入口；`false` 只隐藏入口，分类关系、英文网址、分类索引和全站统计不变。

配置列表的顺序决定可见分类的菜单顺序。已配置但没有文章的分类仍有空列表页。未配置的目录使用目录名作为分类名，但不会自动增加菜单入口；子目录可以继续在 `sections` 声明显示名。例如 `notes/reading/book.md` 形成两级分类，地址 `/categories/notes/reading/`。

「其他页面」由 `nav_misc` 配置：

```yaml
nav_misc:
  label: 其他页面
  icon: folder_open
  path: /misc/
```

它收录没有归入任何 `sections` 分类的文章和独立内容页。`nav: false` 不改变归属：隐藏「开发」入口后，开发文章仍不进入「其他页面」。

## 社交链接

```yaml
social:
  github: https://github.com/flipiris
  wikidot: https://scp-wiki-cn.wikidot.com/flipiris/
  x: https://x.com/flipiris
  bangumi: https://bgm.tv/user/flipiris
```

四个入口紧贴全站信息下方，保留一道分割线；宽屏与抽屉一致，不沉到抽屉底部。填写完整个人主页链接；空值显示禁用按钮。GitHub、X 保留 SVG 标志，wikidot 入口使用 SCP 基金会官方主题图标，Bangumi 使用官方开源前端的吉祥物标志；图标均本地保存，以单色显示并跟随链接文字色；悬停与键盘焦点时使用强调色，昼夜模式下行为一致。悬停或辅助阅读可见完整名称。

# 使用搜索与昼夜切换

宽屏的按钮居中位于 `site-menu` 顶部，与索引入口之间有一道分割线；宽度不超过 860px 时，移至顶栏右侧、信息按钮左边。没有信息窗的 `page` 布局直接靠右。完整 HTML 画布无论宽窄都使用顶栏工具。

## 本地全文搜索

点击搜索或按 `Ctrl / ⌘ K`，输入标题、标签或正文中的词。空格分隔多个关键词时，页面必须同时包含这些词；匹配不区分大小写与全半角。标题命中优先于标签和正文，结果显示对应正文片段。

首次打开时加载 `/search.json`，加载失败可点击「重新加载」。关闭按钮、Esc 或点击弹窗外可退出，焦点回到搜索按钮。查询在浏览器本地完成，不发送给外部搜索服务。

索引包括已发布文章、作品和独立内容页，不包括草稿、CSS/JS 等资源页或自动生成的分类等索引。完整 HTML 画布也搜索正文，排除 head、脚本与样式。索引随构建更新；只改线上文章文件而不重新构建，不会更新搜索内容。

## 昼夜模式

按钮按「跟随系统 → 日间 → 夜间」循环，默认跟随系统。图标显示当前选择：自动亮度表示跟随系统，太阳表示日间，月亮表示夜间；悬停提示同时说明当前状态和下次点击的目标。

- 跟随系统：实时响应操作系统的深浅外观变化。
- 日间：保留页面自己的亮色配色；原本为 `ink` 的页面使用默认亮色。
- 夜间：统一使用 `ink`。

选择保存在浏览器中，刷新、切页和同源标签页间保持同步。浏览器禁用本地存储时，当前页仍可切换，但无法跨页面记忆。文章的 `palette` 元数据不变；完整 HTML 作品 iframe 内的自有样式不跟随外壳切换。

外观实验室选择配色时，暂时按所选配色展示，避免模式偏好遮住预览；这项预览不会改写已保存的模式。点击站点模式按钮则会保存新选择。

# 元数据与布局

| 字段 | 用法 |
| --- | --- |
| `title` | 标题 |
| `date` / `updated` | 发布 / 更新日期；省略 updated 时按站点配置取文件修改时间 |
| `permalink` | 固定网址，如 `night-notes/` |
| `layout` | `article`、`page`、`canvas` |
| `palette` | `rose`（默认亮色）、`tech`、`wanderers`、`sepia`、`ink` |
| `typography` | `standard`、`enhanced`、`literary`、`poem` |
| `alignment` | `centered`（默认）或 `balanced`，作用于 page 布局 |
| `tags` | 标签数组，如 `[阅读, 随笔]` |
| `author` / `description` | 作者、描述；省略时用站点配置 |
| `styles` / `scripts` | 页面专属 CSS / JS 路径数组 |
| `canvas_base` | 完整 HTML 画布的素材基址，建议以 `/` 结尾 |
| `disableNunjucks` | 内容含模板语法时设 `true`，完整 HTML 作品建议开启 |

配色与排版独立。未指定 typography 的「笔记」自动用 `enhanced`，其他内容使用标准排版。显式 `standard` 可关闭笔记自动高亮。

| 布局 | 正文形态 | 标题 | 信息窗 | 文章页脚 |
| --- | --- | --- | --- | --- |
| article | 700px 阅读纸张 | 有 | 有 | 有 |
| page | 800px 无纸张页面 | 有 | 无 | 无 |
| canvas + Markdown | 800px 最简容器 | 无 | 有 | 无 |
| canvas + 完整 HTML | 宽屏保留紧凑页脚；窄屏铺满顶栏以下 | 无 | 顶栏抽屉 | 无 |

完整 HTML 画布在窄屏（不超过 860px）隐藏站点页脚，宽屏使用一行紧凑页脚；其他布局的站点页脚不变。完整 HTML 的判定是渲染正文包含 `<html ...>` 标签，不要求它必须是首个字符；建议正文使用标准的完整 HTML 文档。

# 单页素材与画布

素材放到 `source/attachments/<页面名>/`，构建后地址为 `/attachments/<页面名>/`。它是附件目录，不是「作品」分类。

## Markdown 页面加载专属资源

```yaml
styles: [/attachments/night-journey/style.css]
scripts: [/attachments/night-journey/main.js]
```

首页的介绍和配图在 `source/_data/home.md`，主题只在首页自动加载 `attachments/home/home.css`。独占段落的图片可用 title 生成图注：

```markdown
![河岸](/attachments/night-journey/river.jpg "清晨的河岸")
```

首页的 `<blockquote class="home-profile">` 始终保持头像在左并上下居中、介绍在右，`<div>` 内写 Markdown 介绍；Markdown 与 HTML 标签之间保留空行。宽容器保留 80% 最大宽度；容器宽度 480px 及以下放开至 100%，同时缩小头像和内边距，为文字留出空间。正文配图宽屏时靠右浮动，窄屏时回到上方。

## 完整 HTML 画布

保存为 `source/_posts/works/night-journey.html`：

```html
---
title: 夜行
date: 2026-11-12
permalink: night-journey/
layout: canvas
canvas_base: /attachments/night-journey/
disableNunjucks: true
---
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 id="opening">开篇</h1>
  <p>作品正文。</p>
  <script src="main.js"></script>
</body>
</html>
```

CSS、JS、图片放进 `source/attachments/night-journey/`；作品内部继续使用相对路径，主题插入的 base 负责解析。不要用外层 `styles` / `scripts` 为 iframe 内部加载资源。

作品在 sandbox iframe 中运行，允许脚本、弹窗、下载和用户触发的顶层跳转，不授予同源访问。主题注入 `canvas-bridge.js` 同步大纲、进度。现有示例是 `/scp-cn-4001/`，源文件 `source/_posts/works/4001.html`，部分外部插画和字体仍需联网。

## 信息窗注释

article 和 canvas 的 `div.note` 会从普通正文中抽出，放进信息窗「注释」页签。多个块按出现顺序合并。完整 HTML 作品保留自己的文档正文；外层信息窗仍可读取注释。

在 Markdown 文件中，`div.note` 的开闭标签与内容之间都留空行，否则链接与强调会被当作普通 HTML 文本：

```markdown
<div class="note">

本文曾发表过[该版本](https://example.org/work)。

</div>
```

## 成人内容警告

为页面添加精确标签 `成人内容`，进入时会遮住整个 `content-page`，站点导航仍可使用：

```yaml
tags: [成人内容]
```

遮罩内的标题、说明与「继续阅读」链接在顶部水平居中，只保留「内容警告」标题。默认说明为「本页含有成人内容，仅适合年满 18 周岁的读者。请确认你愿意阅读后再继续。」点击链接后遮罩淡出、正文轻柔显现；开启「减少动态效果」时直接切换。刷新、重新进入或通过浏览器后退返回时都需再次确认，不保存阅读许可。article、page、Markdown 画布和完整 HTML 画布均支持。

需要替换说明时，在正文加入 `div.content-warning`，Markdown 与标签之间保留空行：

```markdown
<div class="content-warning">

本文涉及**性暴力与自伤**描写，阅读前请留意自身状态。

</div>
```

这个块只替换警告说明，不改标题和继续阅读链接；多个块按顺序合并，空块使用默认说明。块内容不会重复出现在正文、信息窗大纲、搜索文本或正文字数中；仅添加块而不加标签不会启用遮罩。完整 HTML 画布可将块写在自己的 body 中，主题会将它移到 iframe 外的警告层。浏览器禁用 JavaScript 时遮罩照常显示，「继续阅读」仍然可用：它是指向正文的锚点链接，点击后遮罩收起、正文可读，只是没有淡出动画。

# 网址、检查与发布

根配置使用 `permalink: :title/`，并设置：

```yaml
pretty_urls:
  trailing_index: false
  trailing_html: false
```

主题生成干净链接 `/night-notes/`，物理文件仍是 `public/night-notes/index.html`。这两个选项控制生成链接，不创建 HTTP 重定向；旧地址的响应由本地服务器或线上托管决定。

```bash
npm run test:theme
npm run build
```

测试通过后检查宽屏、矮屏、手机和完整 HTML 画布：工具位置正确、索引并排、社交不贴底，搜索可输入/关闭/重试，昼夜选择刷新后保留，正文没有横向溢出。已有长文还应检查大纲、进度和注释页签。

提交源文件并推送 `main`，由 GitHub Actions 发布；不要提交 `public/`、`db.json`，不要运行 `hexo deploy`。

# 排查

| 现象 | 处理 |
| --- | --- |
| 配置修改没生效 | 重启本地预览 |
| 旧页面、旧素材还在 | `npm run clean && npm run build` |
| 搜索加载失败 | 确认构建生成了 `public/search.json`，并通过 HTTP 预览而非直接打开 HTML 文件 |
| 搜索缺少新文章 | 重新构建，并检查文章是否仍为草稿 |
| 夜间切换后作品内部不变 | 完整 HTML 作品有独立样式，按钮只切换站点外壳 |
| 分类显示不对 | 检查 `_posts/` 下的目录和 sections，不看 front matter 的 categories |
| 隐藏分类仍在索引出现 | nav 只控制菜单入口；这是预期行为 |
| 抽屉变成一条窄条 | 检查触发器祖先是否有 transform 或 backdrop-filter，导致 fixed 包含块变化 |
| 画布素材 404 | 检查 canvas_base 和 `/attachments/<页面名>/` 下的文件 |
| 页面专属样式没加载 | 检查 styles / scripts 的数组路径；外观实验室资源目录是 appearance-lab |
