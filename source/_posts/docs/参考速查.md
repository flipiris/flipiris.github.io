# 参考速查

面向日常写作、改样式、加页面和验收。站点结构、画布规则与发布流程的说明见 [README](../README.md)；模板与脚本如何协作见 [代码逻辑](code-logic.md)。

## 命令

| 用途 | 命令 |
| --- | --- |
| 安装依赖 | `npm install` |
| 本地预览 | `npm run server` |
| 草稿预览 | `npm run server -- --draft` |
| 构建 | `npm run build` |
| 清空生成物 | `npm run clean` |
| 清空后构建 | `npm run clean && npm run build` |
| 主题测试 | `npm run test:theme` |
| 新建文章 | `npm run new -- --slug first-essay "第一篇文章"` |
| 新建独立页 | `npm run page -- about` |
| 新建画布 | `npm run canvas -- --slug night-journey "夜行"` |
| 新建草稿 | `npm run draft -- --slug unfinished "未完成"` |
| 发布草稿 | `npx hexo publish unfinished` |

预览地址：<http://localhost:4000/>。改了根配置或主题配置后重启预览。

## 目录

```text
_config.yml                         站点、网址、默认布局、分页、pretty_urls
scaffolds/                          文章、画布、页面、草稿模板
source/
  _posts/
    notes/                          笔记（默认 enhanced）
    articles/                       文章
    reviews/                        评论
    works/                          作品（article 或 canvas）
  _data/home.md                     首页介绍与配图
  appearance/index.md               外观实验室
  attachments/                      单页资源与作品素材，发布到 /attachments/
    home/home.css
    appearance/style.css
    appearance/script.js
    scp-cn-4001/
themes/iris-paper/
  _config.yml                       sections、导航、社交、卡片分页
  layout/                           EJS 外壳与三种内容布局
  scripts/                          分类、索引、统计、正文处理
  source/css/                       主题通用样式
  source/js/                        导航、阅读、画布通信
  source/fonts/                     自托管字体分块
  test/                             单元、交互与真实构建测试
docs/                               本页与代码逻辑
```

`source/attachments/` 是附件目录，不是分类；`source/_posts/works/` 才是「作品」分类。

## 元数据

| 字段 | 作用 | 常用值 / 默认 |
| --- | --- | --- |
| `title` | 页面标题 | 必填 |
| `date` | 发布日期 | 建议保留脚手架生成的日期 |
| `updated` | 更新日期 | 省略时用文件修改时间 |
| `permalink` | 固定网址 | 建议以 `/` 结尾，如 `first-essay/` |
| `layout` | 内容布局 | `article` / `page` / `canvas` |
| `typography` | 排版预设 | `standard` / `enhanced` / `literary` / `poem` |
| `palette` | 配色 | `rose` / `tech` / `wanderers` / `sepia` / `ink` |
| `alignment` | 页面对齐 | `centered`（默认）/ `balanced`，主要给 `page` |
| `author` | 作者 | 省略时用站点作者 |
| `tags` | 标签 | 列表或行内数组 |
| `description` | 页面描述 | 省略时用站点描述 |
| `styles` | 页面专属样式 | 路径数组，如 `/attachments/night/style.css` |
| `scripts` | 页面专属脚本 | 路径数组，如 `/attachments/night/main.js` |
| `canvas_base` | 完整 HTML 画布的素材基址 | 如 `/attachments/scp-cn-4001/` |
| `disableNunjucks` | 关闭模板解析 | 正文含 `{{ }}` / `{% %}` 时设为 `true` |

`typography` 省略时：笔记分类自动用 `enhanced`，其余用 `standard`。显式填写会覆盖自动值。

## 布局对照

| `layout` | 宽度 | 纸张 | 标题 | 信息窗 | 文章页脚 | 站点页脚 |
| --- | --- | --- | --- | --- | --- | --- |
| `article` | 700px | 有 | 有 | 有 | 有 | 有 |
| `page` | 800px | 无 | 有 | 无 | 无 | 有 |
| `canvas` + `.md` | 800px | 无 | 无 | 有 | 无 | 有 |
| `canvas` + 完整 HTML | 顶栏 + 剩余视窗 | 无 | 无 | 有（顶栏抽屉） | 无 | 有 |

完整 HTML 画布的判定：正文以 `<html` 开头（允许前面有空白）。否则按片段处理，直接放进正文容器。

## 网址

根 `_config.yml`：

```yaml
pretty_urls:
  trailing_index: false
  trailing_html: false
```

| 写法 | 结果 |
| --- | --- |
| `permalink: appearance/` | `/appearance/` |
| `permalink: scp-cn-4001/` | `/scp-cn-4001/` |
| 不带 `permalink` 的文章 | 默认 `:title/` |
| 访问 `/xxx/index.html` | 301 到 `/xxx/` |
| 访问 `/xxx.html` | 404，不再作为入口 |

页面内的站内链接统一走 `url_for()` / `full_url_for()`，会跟随上述规则。画布素材地址是 `/attachments/...`，不经过 `permalink`。

## 分类与导航

目录决定分类，front matter 的 `categories` 不生效。主题 `_config.yml`：

```yaml
sections:
  - folder: notes
    label: 笔记
    icon: edit_note
  - folder: works
    label: 作品
    icon: palette

nav_primary:
  - label: 最近更新
    path: /updates/
  - label: 页面一览
    path: /archives/

nav_misc:
  label: 其他页面
  icon: folder_open
  path: /misc/
```

- `folder` 同时决定目录名和英文分类地址；未配置的目录直接用目录名。
- `sections` 的顺序就是导航顺序；没有文章的栏目也会生成空列表页。
- `nav_misc` 收录没有归入这些分类的文章与独立页。
- `nav_primary` 是不带图标的固定入口。
- `social` 填 `github` / `x`；留空显示禁用按钮。
- `taxonomy_per_page` 控制分类/标签索引每页卡片数，`taxonomy_preview` 控制每卡预览篇数。

## 单页资源

统一放在 `source/attachments/`，按页面分目录，构建后可直接访问 `/attachments/...`。

| 页面 | 文件 | 引用方式 |
| --- | --- | --- |
| 首页 | `attachments/home/home.css` | `layout.ejs` 在首页自动加载 |
| 外观实验室 | `attachments/appearance/style.css`、`script.js` | `source/appearance/index.md` 的 `styles` / `scripts` |
| 传汐引潮 | `attachments/scp-cn-4001/` | `canvas_base: /attachments/scp-cn-4001/` |

新增页面专属样式：

1. 在 `source/attachments/<slug>/` 放 CSS / JS。
2. 页面元数据写 `styles: [/attachments/<slug>/style.css]`、`scripts: [...]`。
3. 完整 HTML 画布不要把资源写到外层 `styles` / `scripts`，而是在 HTML 里用相对路径引用，`canvas_base` 负责基址。

## 样式与脚本顺序

```text
base → fonts → layout → navigation → pages → prose → info → presets
→ compact（max-width: 860px；完整 HTML 画布始终加载）
→ home（仅首页）
→ page.styles（页面专属）
```

| 文件 | 职责 |
| --- | --- |
| `base.css` | 变量、基础元素、滚动条、动效降级 |
| `fonts.css` | 字体注册表，工具生成，不手改 |
| `layout.css` | 外壳、网格、页眉页脚、画布容器 |
| `navigation.css` | 导航树、侧栏、抽屉、社交、画布外壳配色 |
| `pages.css` | 标题、列表、分类卡片、分页 |
| `prose.css` | 正文、图注、诗歌、逐段浮现 |
| `info.css` | 信息窗、页签、大纲、进度条 |
| `presets.css` | 五套配色、四套排版 |
| `compact.css` | 窄屏抽屉与顶栏；完整 HTML 画布始终启用 |
| `attachments/home/home.css` | 首页专用 |

断点是 **860px**。修改断点时同步两处：`layout.ejs` 的 `compact.css` media 与 `navigation.js` 的 `matchMedia`；再跑一遍窄屏与平板尺寸的验收。Markdown 画布在宽屏使用常驻侧栏；完整 HTML 画布固定使用顶栏 + 抽屉，画布铺满顶栏与站点页脚之间。

## 画布通信

完整 HTML 画布在 sandbox iframe 中运行，主题注入 `/js/canvas-bridge.js`，并插入 `<base href="...">`。

| 方向 | 消息 | 作用 |
| --- | --- | --- |
| iframe → 父页 | `{type: 'iris:canvas-progress', progress, section}` | 同步阅读进度与当前章节 |
| 父页 → iframe | `{type: 'iris:canvas-section', id}` | 点击大纲时滚动到对应 `id` |

父页在存在 `.post-info` 且检测到 `.canvas-document` 时监听。完整 HTML 画布的信息窗从顶栏右侧打开，因此消息会同时更新外层进度条与大纲高亮。

sandbox 允许脚本、弹窗、下载和用户触发的顶层跳转，不授予 `allow-same-origin`。作品内部脚本无法访问父页 DOM。

## 常用操作

### 新建一篇文章并归入分类

```bash
npm run new -- --slug night-notes "夜记"
mkdir -p source/_posts/notes
mv source/_posts/night-notes.md source/_posts/notes/
```

打开文件，补 `permalink: night-notes/`，重启或等待预览刷新。

### 移动已有文章到另一个分类

先填固定 `permalink`，再移动文件。只移动文件会让默认网址跟着文件名/目录变化。

### 新建独立页并加入导航

```bash
npm run page -- about
```

在主题 `_config.yml` 的 `nav_primary` 增加：

```yaml
  - label: 关于
    path: /about/
```

### 新建 Markdown 画布

```bash
npm run canvas -- --slug night-journey "夜行"
mkdir -p source/_posts/works
mv source/_posts/night-journey.md source/_posts/works/
```

补 `permalink`，保持 `layout: canvas`。正文直接写 Markdown。

### 新建完整 HTML 画布

1. 新建 `source/_posts/works/night-journey.html`。
2. 写元数据：`layout: canvas`、`permalink`、`canvas_base`、`disableNunjucks: true`。
3. 正文从 `<html` 开始，保存完整文档。
4. 素材放进 `source/attachments/night-journey/`。
5. `npm run clean && npm run build` 验证。

### 增加导航入口

在 `nav_primary` 增加 `label` / `path`；分类入口只改 `sections`。不要为调试页单独加分类。

### 增加配色或排版

1. 在 `content-blocks.js` 的 `PALETTES` / `TYPOGRAPHIES` 增加名字。
2. 在 `presets.css` 增加 `data-palette` / `data-typography` 规则。
3. 运行 `npm run test:theme`；预设名称与 CSS 有对应测试。
4. 用 `/appearance/` 预览并检查对比度。

## 验收

```bash
npm run test:theme
npm run build
```

浏览器检查尺寸：

- 桌面 1440×900，矮屏 1440×700
- 平板竖屏 820×1180，横屏 1180×820
- 手机 390×844

检查项：

- 页面不横向溢出；侧栏、信息窗与顶栏不互相遮挡。
- 宽屏侧栏常驻；窄屏抽屉可开合、Esc 关闭、焦点返回。
- 长文进度、目录高亮、注释页签正常。
- 完整 HTML 画布保留顶栏与站点页脚，画布铺满两者之间的剩余视窗；窄屏同样如此。
- Markdown 画布是 800px 容器，侧栏与信息窗正常。
- 首页只加载 `attachments/home/home.css`；其他页面不加载。
- `/appearance/` 可切换布局、配色、排版；`/appearance.html` 不再作为入口。

## 排查

| 现象 | 检查 |
| --- | --- |
| 改了配置没生效 | 重启 `npm run server` |
| 旧页面/旧素材还在 | `npm run clean && npm run build` |
| `/xxx.html` 404 | 预期行为，使用 `/xxx/` |
| 抽屉只有一条窄条 | 祖先元素是否加了 `backdrop-filter` / `transform`，它们会成为 fixed 子元素的包含块 |
| HTML 画布空白 | 正文是否以 `<html` 开头；`canvas_base` 是否以 `/` 结尾；资源是否在 `source/attachments/` |
| 画布素材 404 | 路径应是 `/attachments/<slug>/...`，不是 `/works/...` |
| Markdown 画布没有标题 | `canvas` 布局本来就隐藏标题与文章页脚 |
| 首页样式 404 | 文件应在 `source/attachments/home/home.css` |
| 分类不对 | 看文件在 `source/_posts/` 下的目录，不看 `categories` |
| 网址变了 | 先补 `permalink`，再移动文件 |
